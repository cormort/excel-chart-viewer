# Excel/CSV 讀取與圖表產生器

單一 HTML 檔的資料視覺化工具。在瀏覽器裡讀取 Excel/CSV，直接產生互動圖表與可排序的資料表格。

**線上使用：** https://cormort.github.io/excel-chart-viewer/

檔案完全在瀏覽器端解析，不會上傳到任何伺服器。

## 功能

| 分頁 | 說明 |
|---|---|
| 讀取檔案 | 選擇 `.xlsx` / `.xls` / `.csv`（含 BOM） |
| 資料表格 | 點欄位標題排序（數值/文字自動判斷）、關鍵字跨欄篩選 |
| 基本圖 | 折線、直條、橫條、散佈、面積、圓餅 |
| 組合圖 | 兩個系列各自選型別，雙 Y 軸 |
| 預算決算 | 基金別 / 計畫名稱連動篩選，年度預算 vs 決算對照 |

兩個圖表分頁都可以先做**資料切片**：挑一個欄位、挑一個值，之後的 X/Y 只吃切出來的那些列。
例如先選「年度 = 105」，X 軸選計畫名稱、Y 軸選預算數，畫出來就是該年度各計畫的預算。
切片條件會標在圖表副標題上，旁邊也會顯示符合幾筆。

每張圖右上角的工具列可以存成 PNG、檢視原始資料表、區域縮放。

「預算決算」分頁需要檔案含有 `基金名稱`、`計畫名稱`、`年度`、`預算數`、`決算數` 這幾個欄位，否則會自動停用並提示缺少哪些欄。

## 使用

線上開啟即可，或下載 `index.html` 用瀏覽器打開（需連網載入 CDN 上的兩個函式庫）。

## 相依套件

皆為 Apache-2.0，透過 cdnjs 載入：

- [SheetJS](https://sheetjs.com/) 0.18.5 — 解析 xlsx / xls / csv
- [Apache ECharts](https://echarts.apache.org/) 5.6.0 — 繪圖
