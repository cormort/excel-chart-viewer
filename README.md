# Excel/CSV 讀取與圖表產生器

單一 HTML 檔的資料視覺化工具。在瀏覽器裡讀取 Excel/CSV，直接產生互動圖表與可排序的資料表格。

**線上使用：** https://cormort.github.io/excel-chart-viewer/

檔案完全在瀏覽器端解析，不會上傳到任何伺服器。

## 功能

| 分頁 | 說明 |
|---|---|
| 讀取檔案 | 選擇 `.xlsx` / `.xls` / `.csv`（含 BOM）；活頁簿有多個工作表時可切換 |
| 資料表格 | 點欄位標題排序（數值/文字自動判斷）、關鍵字跨欄篩選 |
| 基本圖 | 折線、直條、橫條、散佈、面積、圓餅 |
| 組合圖 | 兩個系列各自選型別，雙 Y 軸 |
| 預算決算 | 基金別 / 計畫名稱連動篩選，年度預算 vs 決算對照 |

## 資料切片與彙總

兩個圖表分頁都可以先做**資料切片**：挑一個欄位、挑一或多個值，之後的 X/Y 只吃切出來的列。

統計上這是把 panel data（縱橫資料）降成一個維度：

| 固定哪一維 | 剩下什麼 | 統計學名稱 |
|---|---|---|
| 年度 = 105 | 單一時點 × 多個計畫 | cross-sectional data（橫斷面） |
| 計畫 = 計畫_07 | 單一計畫 × 多個年度 | time series data（時間序列） |

**多選**時每個值各自成為一條 series，可以直接跨組比較（例如同時選 105、106、107
三個年度，各計畫就有三根柱子並排）。

**彙總方式**處理 X 軸有重複值的情形：不切片而把 X 選成計畫名稱時，同一個計畫會在
每個年度各出現一次；選「加總」就變成各計畫的十年總預算，另有平均與筆數。選了多組
篩選值卻沒選彙總方式時會擋下來，因為各組的 X 類別無法對齊。

切片與彙總條件會標在圖表副標題，控制列旁顯示符合幾筆。

圖表的欄位選擇會依「欄位組合」記在瀏覽器的 `localStorage`，下次載入同樣格式的檔案
時自動還原。

每張圖右上角的工具列可以存成 PNG、檢視原始資料表、區域縮放。

「預算決算」分頁需要檔案含有 `基金名稱`、`計畫名稱`、`年度`、`預算數`、`決算數` 這幾個欄位，否則會自動停用並提示缺少哪些欄。

## 使用

線上開啟即可，或下載 `index.html` 用瀏覽器打開（需連網載入 CDN 上的兩個函式庫）。

## 相依套件

皆為 Apache-2.0，透過 cdnjs 載入：

- [SheetJS](https://sheetjs.com/) 0.18.5 — 解析 xlsx / xls / csv
- [Apache ECharts](https://echarts.apache.org/) 5.6.0 — 繪圖
